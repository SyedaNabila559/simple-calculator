# 🧮 Simple Calculator with Python and Streamlit

A **Simple Calculator** built using **Python** and **Streamlit**. This app allows users to perform basic arithmetic operations such as **Addition**, **Subtraction**, **Multiplication**, and **Division**, and it includes fun emojis to make the experience more engaging!

## Features 🚀:
- **Addition ➕**, **Subtraction ➖**, **Multiplication ✖️**, and **Division ➗** operations.
- Fun and interactive UI with emojis 🎉.
- Simple and easy-to-use interface 💻.
- Displays results with emojis 🎉.

## Prerequisites 🛠️:
Before running the app, ensure you have **Python** installed. You will also need to install the following dependencies:

- Streamlit
- Python's built-in libraries
